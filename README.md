# Test Plan - QA
This repository contains the test plan for the Web-Based Film Ticket Booking System for ABC Cinema.

## Overview
This test plan outlines the strategies, procedures, and methodologies that will be followed for testing the ABC Cinema Film Ticket Booking System. The goal is to ensure that the system meets functional and non-functional requirements, is secure, user-friendly, and performs effectively under different conditions.

## Contents
- **ABC_Cinema_TestPlan.pdf**: The main document that describes the test plan for the Web-Based Film Ticket Booking System, including the test methodology, test levels, resources needed, and roles/responsibilities.

## Test Plan Key Highlights:
- **Scope**: Functional and non-functional requirements, including customer management, staff management, booking management, and payment management.
- **Test Methodology**: Agile methodology with Unit Testing, Integration Testing, System Testing, and User Acceptance Testing (UAT).
- **Test Deliverables**: Test cases, bug reports, test execution reports.
- **Testing Tools**: JIRA for bug tracking, Selenium for functional automation, Apache JMeter for performance testing.

For any further queries, please refer to the test plan document.
